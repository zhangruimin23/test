## 5. 测试产物

测试产物路径：`data-requirements-verify/`

- `help.txt`：CLI 帮助输出。
- `invalid-source.txt`：不支持数据源的错误输出。

## 6. 环境限制与真实接口验证

已执行不带 `--mock` 的真实 API 验证：

```powershell
python .\dataeng_cli.py fetch --source pubchem --query aspirin --output .\data-requirements-verify\live
```

结果为退出码 `1`，错误原因如下：

```text
PubChem is unavailable after 3 attempts: CERTIFICATE_VERIFY_FAILED:
self-signed certificate in certificate chain
```

根因是当前运行环境的 HTTPS 代理使用自签名证书，Python 默认不信任该证书链。程序已执行 3 次重试并输出明确的“数据源不可达”错误。请在不经过该代理的网络中运行，或将企业根证书加入 Python 信任链；不建议关闭 TLS 证书验证。

本机也未检测到 `docker` 和 `make` 可执行命令，因此 Dockerfile 和 Makefile 已完成文件级交付，但未在当前机器实际运行。
